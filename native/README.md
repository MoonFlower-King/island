# Island 原生版（预览）

用 Rust 重写的灵动岛，直接使用 Windows 的合成引擎（Windows.UI.Composition）和 Direct2D。

| | WPF 版（1.x） | 原生版 |
|---|---|---|
| 下载体积 | 约 116 MB（自带 .NET） | **约 0.3 MB** 单个 exe |
| 内存 | 80 – 150 MB | **约 35 MB**（工作集，私有约 16 MB） |
| 动画 | 界面线程逐帧计算，分层窗口每帧从显卡拷回内存 | **系统合成器独立线程运行**，界面线程不参与 |
| 依赖 | .NET 8 运行时（或打包进 exe） | 无 |

数字来自 CI 上的冒烟测试（Windows Server，无显卡）。

## 现在能用的

- 胶囊：待机细线、音乐胶囊、音量提示、展开面板之间的弹簧形变，内容淡入和缩放
- 悬停展开、离开收起；透明区域鼠标穿透，不挡下面的窗口
- **停靠位置**：顶部、左侧、右侧（两侧时待机是竖线，从侧面展开）
- **音乐**（SMTC）：封面、歌名、歌手、律动条、上一首 / 播放暂停 / 下一首、进度、可拖动的音量条；网易云音乐这类不报告进度的播放器由岛自己计时，网易云的时长从本地播放记录读取；可以设置放音乐时也收成细线（细线变成封面主题色）
- **剪贴板历史**：最近 50 条文字，点一下重新复制，跳过密码管理器标记的内容，和 WPF 版共用 clipboard.json
- **系统监控**：CPU、内存、实时网速（只在标签打开时每秒采样）
- **外观**：黑夜 / 白天 / 跟随系统 / 按时间 / 自定义（色块），待机样式、放音乐时的样式、停靠位置
- **音量 / 亮度提示**：调节系统音量或笔记本亮度时短暂显示；鼠标停在岛上滚滚轮调音量
- 置顶、全屏时自动隐藏、多显示器缩放（DPI）变化
- 右键菜单：置顶、音量提示开关、剪贴板保存开关、开机自动启动、打开数据文件夹、退出
- 设置和 WPF 版共用 settings.json，只改自己认识的字段，两个版本可以来回切换

还没做：待办、文件中转站、AI 翻译（需要文字输入框），以及自定义主题的 `#RRGGBB` 输入、"按时间"的时段修改。

## 架构

```
native/src/
├── lib.rs        与平台无关、有单元测试的部分
│   ├── metrics   各状态的形状、悬停热区
│   ├── state     状态优先级、悬停进出延迟
│   ├── color     封面取色、对比度
│   └── text      时间格式化
└── win/          Windows 部分
    ├── app       窗口、消息循环、状态机、鼠标穿透
    ├── scene     合成树和所有动画
    ├── gfx       D3D11 / Direct2D / DirectWrite 设备
    ├── views     内容绘制和按钮布局
    ├── media     系统媒体控制（后台线程）
    └── smoke     冒烟测试
```

- 胶囊的形状只由 4 个数（宽、高、圆角、上边距）决定，放在一个合成属性集里。状态切换时对它们启动弹簧动画，背景、裁剪、内容位置都用表达式动画绑定上去。
- 内容（文字、图标、封面）只在变化时用 Direct2D 画进合成表面，按最终尺寸画一次；胶囊动画时只是裁出可见部分。
- 窗口是固定大小的透明区域，平时鼠标穿透。每 40 ms 看一次光标，碰到岛的范围才变成可点击。
- 没有显卡（虚拟机、远程桌面）时合成器的阴影效果会画成黑块，检测到软件渲染就不画阴影。

## 开发

需要 Rust（版本固定在 `rust-toolchain.toml`，rustup 会自动安装）。

```bash
cargo test
```

```bash
cargo run --release
```

只有 `lib.rs` 那部分能在非 Windows 系统上测试。在 Linux / macOS 上也可以做类型检查：

```bash
cargo clippy --target x86_64-pc-windows-msvc
```

冒烟测试：`Island.exe --smoke-test <输出目录>`，会走一遍各个状态、截图，并检查屏幕上真的画出了胶囊。
