# Island 原生版（预览）

用 Rust 重写的灵动岛，直接使用 Windows 的合成引擎（Windows.UI.Composition）和 Direct2D。

| | WPF 版（1.x） | 原生版 |
|---|---|---|
| 下载体积 | 约 116 MB（自带 .NET） | **约 0.6 MB** 单个 exe |
| 内存 | 80 – 150 MB | **刚启动约 27 MB**（私有约 9 MB）；翻译、输入法、拖放这些功能第一次用到时会加载系统组件，全部用过一遍后约 87 MB |
| 动画 | 界面线程逐帧计算，分层窗口每帧从显卡拷回内存 | **系统合成器独立线程运行**，界面线程不参与 |
| 依赖 | .NET 8 运行时（或打包进 exe） | 无 |

数字来自 CI 上的冒烟测试（Windows Server，无显卡）。

## 现在能用的

- 胶囊：待机细线、音乐胶囊、音量提示、展开面板之间的弹簧形变，内容淡入和缩放
- 悬停展开、离开收起；透明区域鼠标穿透，不挡下面的窗口
- **停靠位置**：顶部、左侧、右侧；两侧时收起的状态（待机、时间、音乐、音量、通知）都是贴边的竖胶囊，从侧面展开；按住面板空白处可以拖到别的边或别的屏幕
- **音乐**（SMTC）：封面、歌名、歌手、律动条、上一首 / 播放暂停 / 下一首、进度、可拖动的音量条；网易云音乐这类不报告进度的播放器由岛自己计时，网易云的时长从本地播放记录读取；可以设置放音乐时也收成细线（细线变成封面主题色）
- **待办**：回车添加，勾选后沉到底部，清除已完成；和 WPF 版共用 todos.json
- **文字输入**：自己画的输入框，支持中文输入法（组字直接显示在框里，候选窗跟着光标）、选中、复制 / 剪切 / 粘贴
- **AI 翻译**：中文翻成英文、其他语言翻成中文，边生成边显示；Claude、OpenAI、DeepSeek、通义千问、Kimi、智谱、Ollama 本地或自定义地址，Anthropic / OpenAI 两种格式；Key 用 Windows DPAPI 加密，和 WPF 版共用配置；用系统自带的 WinHTTP 发请求（跟随系统代理）
- **文件中转站**：把文件拖到岛上暂存（只记路径，不复制），按住拖出去使用，双击打开，可以在资源管理器中显示；和 WPF 版共用 shelf.json
- **剪贴板历史**：最近 50 条文字，点一下重新复制，跳过密码管理器标记的内容，和 WPF 版共用 clipboard.json
- **系统监控**：CPU、内存、实时网速（只在标签打开时每秒采样）
- **外观**：黑夜 / 白天 / 跟随系统 / 按时间（可以改时段）/ 自定义（色块或直接填 `#RRGGBB`），待机样式、放音乐时的样式、停靠位置
- **音量 / 亮度提示**：调节系统音量或笔记本亮度时短暂显示；鼠标停在岛上滚滚轮调音量
- **通知**：临时弹出几秒后自动缩回，点一下关掉；切换声音输出设备（插拔耳机、连上蓝牙）时会提示换到了哪个设备；右键菜单里可以演示
- **其他软件的通知**：微信、QQ、Telegram、X 等所有软件的 Windows 通知都显示在岛上，带软件自己的图标（从本机的通知记录只读读取，右键菜单可以关掉）
- **AI 消息**：Claude Code、Codex 等完成任务或等你确认时弹出提醒，并记在"AI 动态"标签里；没看过的会在收起的胶囊上留一个小点（设置方法见下面）
- **多块屏幕**：在"外观 → 位置"里点屏幕名字切换到下一块屏幕；记住的屏幕拔掉后回到主屏幕
- 置顶、全屏时自动隐藏、多显示器缩放（DPI）变化
- 右键菜单：置顶、音量提示开关、其他软件通知开关、剪贴板保存开关、开机自动启动、打开数据文件夹、退出
- 设置和 WPF 版共用 settings.json，只改自己认识的字段，两个版本可以来回切换

WPF 版的功能已经全部移植。

## 接入 AI 命令行工具

`Island.exe --notify <来源> [JSON]` 会把消息转给正在运行的岛然后马上退出（岛没在运行也正常退出，不会让工具报错）。把下面的路径换成你的 Island.exe：

- **Claude Code**：在 `~/.claude/settings.json` 里加

  ```json
  {
    "hooks": {
      "Stop": [{ "hooks": [{ "type": "command", "command": "\"C:\\Tools\\Island\\Island.exe\" --notify claude" }] }],
      "Notification": [{ "hooks": [{ "type": "command", "command": "\"C:\\Tools\\Island\\Island.exe\" --notify claude" }] }]
    }
  }
  ```

  回答完提醒"完成了任务"（附最后一段回复的摘要），等你批准时提醒"等你确认"。
- **Codex**：在 `~/.codex/config.toml` 里加 `notify = ["C:\\Tools\\Island\\Island.exe", "--notify", "codex"]`
- **其他工具**：`Island.exe --notify 名字 "{\"message\": \"做完了\"}"`，或者把 JSON / 纯文字从标准输入传进来

桌面版的 AI 软件（Claude、Codex、WorkBuddy、DeepSeek 等）不用设置，它们的系统通知会直接显示在岛上。

## 架构

```
native/src/
├── lib.rs        与平台无关、有单元测试的部分
│   ├── metrics   各状态的形状、悬停热区
│   ├── state     状态优先级、悬停进出延迟
│   ├── color     封面取色、对比度
│   ├── ai        AI 工具的消息（Claude Code 钩子、Codex notify）
│   ├── toast     系统通知的 XML
│   └── text      时间格式化
└── win/          Windows 部分
    ├── app       窗口、消息循环、状态机、鼠标穿透
    ├── scene     合成树和所有动画
    ├── gfx       D3D11 / Direct2D / DirectWrite 设备
    ├── views     内容绘制和按钮布局
    ├── media     系统媒体控制（后台线程）
    ├── toasts    读取 Windows 通知记录（后台线程，系统自带的 winsqlite3）
    ├── appinfo   软件的显示名和图标
    ├── forward   Island.exe --notify
    └── smoke     冒烟测试
```

- 胶囊的形状只由 4 个数（宽、高、圆角、上边距）决定，放在一个合成属性集里。状态切换时对它们启动弹簧动画，背景、裁剪、内容位置都用表达式动画绑定上去。
- 内容（文字、图标、封面）只在变化时用 Direct2D 画进合成表面，按最终尺寸画一次；胶囊动画时只是裁出可见部分。
- 窗口是固定大小的透明区域，平时鼠标穿透。每 40 ms 看一次光标，碰到岛的范围才变成可点击。
- 胶囊不用合成器阴影：阴影在缩放不是 100% 的屏幕上会算错尺寸，把背景糊成黑块（2.0.0-alpha.3 修复）。

## 开发

需要 Rust（版本固定在 `rust-toolchain.toml`，rustup 会自动安装）。

```bash
cargo test
```

```bash
cargo run --release
```

只有 `lib.rs` 那部分能在非 Windows 系统上测试。在 Linux / macOS 上也可以做类型检查：

```bash
cargo clippy --target x86_64-pc-windows-msvc
```

冒烟测试：`Island.exe --smoke-test <输出目录>`，会走一遍各个状态、截图，并检查屏幕上真的画出了胶囊。
