# 原生版更新日志

原生版（Rust 重写）的版本单独记录。WPF 版见仓库根目录的 CHANGELOG.md。

## [未发布]

### 改进

- **桌面快捷方式**：第一次运行时自动在桌面放一个"灵动岛"快捷方式，带新画的应用图标（浅色屏幕上方一颗黑色胶囊）。之后删掉了不会再自动放，右键菜单里的"在桌面放快捷方式"可以随时放回或拿掉。把 Island.exe 挪了位置，下次启动时快捷方式会自动改过去
- 岛已经在运行时再双击快捷方式（或再运行一次 Island.exe），会让岛展开，不再什么反应都没有

### 其他

- 仓库里移除了已停止维护的 1.x（WPF 版）源码和它的构建流程。已经发布的 1.x 下载包不受影响；从 1.x 升级的设置和数据照样沿用
- 清理：冒烟测试不再测量早已不用的旧动画参数；`--notify` 不再接收 2.0.1 及以前的旧消息格式（钩子里的 Island.exe 和正在运行的岛是同一个版本时没有影响）；更正过时的注释

## [2.0.4]

下载 `Island-native-2.0.4-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后替换原来的 `Island.exe` 即可，设置和数据都保留。

### 改进

- **任务栏通知区有了岛的图标**：点一下展开或收起岛，右键打开和岛上一样的菜单（置顶、开机启动、退出等）。有没看过的 AI 消息或等你批准的操作时，图标右上角会有个橙点。Windows 11 默认把新图标收在"^"里，可以把它拖到任务栏上常驻

## [2.0.3]

下载 `Island-native-2.0.3-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后替换原来的 `Island.exe` 即可，设置和数据都保留。要用 AI 工作台和在岛上批准，记得按 README 在 Claude Code 里加上新的钩子。

### 改进

- **AI 工作台**：展开岛的 AI 标签，能看到每个 Claude Code 会话正在干什么（"运行 npm test"、"改 app.rs"）、你交给它的任务、改了几个文件、已经跑了多久；做完了自动从工作台拿掉，变成"完成了任务"的消息。点一行跳回那个终端
- **在岛上直接批准**：Claude Code 要运行命令或改文件、需要你同意时，岛上弹出带"允许 / 拒绝"按钮的胶囊，一直停着等你点，点了 Claude Code 就继续干活，不用切回终端。几个请求会排队；展开的 AI 标签里也能点。点胶囊别处 = 回终端自己处理。在终端里先答了的话，岛上的请求会自动消失
- 需要在 Claude Code 的设置里多加几个钩子，见 README 的"接入 AI 命令行工具"

## [2.0.2]

下载 `Island-native-2.0.2-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后替换原来的 `Island.exe` 即可，设置和数据都保留。

### 改进

- **点 AI 消息跳回对话**：在 AI 动态里点一条消息，或者在消息弹出时点它，就会切到发消息的地方：
  - 终端或编辑器里的 Claude Code、Codex（用 `--notify` 接的）：切回当时跑它的那个窗口（命令行、Windows Terminal、VS Code 等，开了几个窗口时挑标题里带项目名的）；窗口最小化了会先还原
  - 桌面版 AI 软件（Claude、Codex 桌面版等）和其他软件的通知：和在 Windows 通知中心里点这条通知一样，交给软件自己打开对应的对话；软件不支持的话，至少把它的窗口切到前面
- 微信、QQ 等其他软件弹出的通知，点一下也会切到那个软件

### 修复

- 网易云音乐的封面有时是上一首歌的：网易云切歌时先报新歌名、过一会儿才换封面，岛之前只在换歌那一刻读一次封面。现在封面图片变了就会更新，换歌后几秒内读到和上一首一样的封面先当作还没换好，稍后再读
- 网易云音乐的进度条常常不显示：之前只在换歌那一刻去播放记录里查一次总时长，新歌还没写进去就查不到。现在还会从网易云的当前播放列表里查，查不到也会在换歌后再查几次
- 鼠标在展开面板上划过时面板会轻轻动一下：
  - 面板和屏幕边之间的空隙之前不算"在岛上"，鼠标划过那里岛会开始收起、马上又展开，现在这段空隙也算在岛上
  - 拖动换位置改成只能按住顶部标签栏的空白处，并且要移动明显一段距离才开始，在内容区点击时手抖不会再挪动面板

## [2.0.1]

下载 `Island-native-2.0.1-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后替换原来的 `Island.exe` 即可，设置和数据都保留。

### 改进

## [2.0.0]

**原生版第一个正式版**，推荐所有人使用。下载 `Island-native-2.0.0-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后运行 `Island.exe`；如果在用 WPF 版，先退出它，两个版本共用设置和数据，可以直接切换。exe 没有数字签名，第一次运行如果提示"已保护你的电脑"，点"更多信息" → "仍要运行"。需要 Windows 10 1903 或更新版本。

和 2.0.0-alpha.4 相比没有改动，包含 alpha.1 到 alpha.4 的全部内容：

- 单个 exe 不到 1 MB，不需要任何运行时；刚启动约 27 MB 内存；动画由系统合成器在独立线程上运行
- WPF 版的全部功能：音乐、待办、剪贴板、中转站、AI 翻译、系统监控、外观、音量和亮度提示、通知、多屏幕
- 原生版新增：其他软件的通知（带软件图标）、AI 完成任务提醒和 AI 动态、侧边竖胶囊、拖动换位置

## [2.0.0-alpha.4]

**预览版**，日常使用请继续用 WPF 版 1.3.0。下载 `Island-native-2.0.0-alpha.4-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后运行 `Island.exe`；先退出 WPF 版。exe 没有数字签名，第一次运行如果提示"已保护你的电脑"，点"更多信息" → "仍要运行"。

### 新功能

- **其他软件的通知**：微信、QQ、Telegram、X、Claude、Codex、WorkBuddy……所有软件弹出的 Windows 通知都会显示在岛上，带那个软件自己的图标；右键菜单"显示其他软件的通知"可以关掉。灵动岛只读取本机的 Windows 通知记录，不改不删，也不上传
- **AI 完成任务提醒**：
  - Claude Code、Codex 等命令行工具可以通过 `Island.exe --notify` 把"完成了任务""等你确认"发给岛（设置方法见 README）
  - AI 软件的桌面版通知也会归到这里
  - AI 提醒多停一会儿（6 秒）；没看过的消息会让待机细线变成强调色、时间和音乐胶囊上多一个小点
- **AI 动态**：展开面板新增"AI 动态"标签，按时间列出每条 AI 消息；有没看过的消息时展开直接打开这个标签
- **侧边竖胶囊**：停靠在左侧或右侧时，待机时间、音乐胶囊、音量提示、通知都变成贴着屏幕边的竖胶囊（和设计预览一致）

### 改进

- **收放更快更顺**：之前弹簧参数用错了单位，展开要 1.2 秒左右才停稳。现在和 WPF 版一样快，在屏幕上实测展开约 0.25 秒到位，收起约 0.1 秒
- **拖动换位置**：按住展开面板的空白处拖动，松手后停靠到最近的一边（顶部、左侧或右侧）；有多块屏幕时可以直接拖到另一块屏幕上

## [2.0.0-alpha.1]

**这是预览版。** 用 Rust 重写的灵动岛，功能和 WPF 1.3.0 基本一致，但只在没有显卡的 CI 虚拟机上做过自动测试，真机上可能还有问题。日常使用请继续用 WPF 版 1.3.0，想尝鲜的话欢迎试用并反馈。

### 和 WPF 版比

- **单个 exe 约 0.6 MB**（WPF 版自带 .NET 约 116 MB），不需要安装任何运行时
- **内存更少**：刚启动约 27 MB；翻译、输入法、拖放第一次用到时会加载系统组件，全部用过一遍后约 87 MB（WPF 版 80 – 150 MB）
- **动画更顺**：胶囊形变和所有动画交给系统合成器在独立线程上运行，界面线程卡住也不影响动画

### 包含的功能

- 待机细线 / 时间小胶囊、音乐胶囊、音量和亮度提示、展开面板之间的弹簧动画
- 停靠在顶部、左侧或右侧；透明区域鼠标穿透；全屏时自动隐藏；置顶
- 音乐：封面、控制、进度（网易云音乐也有）、音量条、律动条，放音乐时也可以只显示细线
- 待办、剪贴板历史、文件中转站（拖进拖出）、AI 翻译（多个服务可选，流式输出）、系统监控
- 外观：黑夜 / 白天 / 跟随系统 / 按时间 / 自定义颜色
- 支持中文输入法
- 和 WPF 版共用设置和数据（settings.json、todos.json、clipboard.json、shelf.json，以及加密保存的翻译 Key），两个版本可以来回切换

### 使用说明

- 下载 `Island-native-2.0.0-alpha.1-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后运行 `Island.exe`
- **先退出 WPF 版**，两个版本同时运行会出现两个岛
- exe 没有数字签名，第一次运行时 Windows 可能提示"已保护你的电脑"，点"更多信息" → "仍要运行"
- 需要 Windows 10 1903 或更新版本
- 右键岛可以设置开机自动启动、打开数据文件夹或退出

### 已知问题

- 动画流畅度、阴影效果和真实输入法、真实翻译服务还没有在有显卡的真机上验证过
