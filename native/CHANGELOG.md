# 原生版更新日志

原生版（Rust 重写）的版本单独记录。WPF 版见仓库根目录的 CHANGELOG.md。

## [2.0.0-alpha.4]

**预览版**，日常使用请继续用 WPF 版 1.3.0。下载 `Island-native-2.0.0-alpha.4-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后运行 `Island.exe`；先退出 WPF 版。exe 没有数字签名，第一次运行如果提示"已保护你的电脑"，点"更多信息" → "仍要运行"。

### 新功能

- **其他软件的通知**：微信、QQ、Telegram、X、Claude、Codex、WorkBuddy……所有软件弹出的 Windows 通知都会显示在岛上，带那个软件自己的图标；右键菜单"显示其他软件的通知"可以关掉。灵动岛只读取本机的 Windows 通知记录，不改不删，也不上传
- **AI 完成任务提醒**：
  - Claude Code、Codex 等命令行工具可以通过 `Island.exe --notify` 把"完成了任务""等你确认"发给岛（设置方法见 README）
  - AI 软件的桌面版通知也会归到这里
  - AI 提醒多停一会儿（6 秒）；没看过的消息会让待机细线变成强调色、时间和音乐胶囊上多一个小点
- **AI 动态**：展开面板新增"AI 动态"标签，按时间列出每条 AI 消息；有没看过的消息时展开直接打开这个标签
- **侧边竖胶囊**：停靠在左侧或右侧时，待机时间、音乐胶囊、音量提示、通知都变成贴着屏幕边的竖胶囊（和设计预览一致）

### 改进

- **收放更快更顺**：之前弹簧参数用错了单位，展开要 1.2 秒左右才停稳。现在和 WPF 版一样快，在屏幕上实测展开约 0.25 秒到位，收起约 0.1 秒
- **拖动换位置**：按住展开面板的空白处拖动，松手后停靠到最近的一边（顶部、左侧或右侧）；有多块屏幕时可以直接拖到另一块屏幕上

## [2.0.0-alpha.3]

**预览版**，日常使用请继续用 WPF 版 1.3.0。下载 `Island-native-2.0.0-alpha.3-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后运行 `Island.exe`；先退出 WPF 版。exe 没有数字签名，第一次运行如果提示"已保护你的电脑"，点"更多信息" → "仍要运行"。

### 修复

- 显示缩放不是 100%（例如 150%）时，展开面板的背景只剩一小块模糊的黑色、内容露在外面。原因是胶囊的阴影只在有显卡的电脑上生效，在缩放下尺寸算错。现在去掉了阴影，改为一圈很淡的细边
- 自动测试改为在 100% 和 150% 两种缩放下都跑一遍

## [2.0.0-alpha.2]

**预览版**，日常使用请继续用 WPF 版 1.3.0。下载 `Island-native-2.0.0-alpha.2-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后运行 `Island.exe`；先退出 WPF 版。exe 没有数字签名，第一次运行如果提示"已保护你的电脑"，点"更多信息" → "仍要运行"。设置和数据与 WPF 版共用。

### 新功能

### 修复

## [2.0.0-alpha.1]

**这是预览版。** 用 Rust 重写的灵动岛，功能和 WPF 1.3.0 基本一致，但只在没有显卡的 CI 虚拟机上做过自动测试，真机上可能还有问题。日常使用请继续用 WPF 版 1.3.0，想尝鲜的话欢迎试用并反馈。

### 和 WPF 版比

- **单个 exe 约 0.6 MB**（WPF 版自带 .NET 约 116 MB），不需要安装任何运行时
- **内存更少**：刚启动约 27 MB；翻译、输入法、拖放第一次用到时会加载系统组件，全部用过一遍后约 87 MB（WPF 版 80 – 150 MB）
- **动画更顺**：胶囊形变和所有动画交给系统合成器在独立线程上运行，界面线程卡住也不影响动画

### 包含的功能

- 待机细线 / 时间小胶囊、音乐胶囊、音量和亮度提示、展开面板之间的弹簧动画
- 停靠在顶部、左侧或右侧；透明区域鼠标穿透；全屏时自动隐藏；置顶
- 音乐：封面、控制、进度（网易云音乐也有）、音量条、律动条，放音乐时也可以只显示细线
- 待办、剪贴板历史、文件中转站（拖进拖出）、AI 翻译（多个服务可选，流式输出）、系统监控
- 外观：黑夜 / 白天 / 跟随系统 / 按时间 / 自定义颜色
- 支持中文输入法
- 和 WPF 版共用设置和数据（settings.json、todos.json、clipboard.json、shelf.json，以及加密保存的翻译 Key），两个版本可以来回切换

### 使用说明

- 下载 `Island-native-2.0.0-alpha.1-win-x64.zip`（ARM 电脑选 `win-arm64`），解压后运行 `Island.exe`
- **先退出 WPF 版**，两个版本同时运行会出现两个岛
- exe 没有数字签名，第一次运行时 Windows 可能提示"已保护你的电脑"，点"更多信息" → "仍要运行"
- 需要 Windows 10 1903 或更新版本
- 右键岛可以设置开机自动启动、打开数据文件夹或退出

### 已知问题

- 动画流畅度、阴影效果和真实输入法、真实翻译服务还没有在有显卡的真机上验证过
