# Island

Windows 上的"灵动岛"：屏幕顶部正中的一个黑色胶囊。鼠标移上去展开成功能面板，移开立刻收起。

推荐使用 2.0 起的原生版（Rust 重写，单个 exe 不到 1 MB）；1.x 的 WPF 版仍然可以下载。

## 下载

到 [Releases](https://github.com/MoonFlower-King/island/releases) 下载最新版本，解压后双击 `Island.exe` 即可，不需要安装。

- **原生版（推荐）**：`Island-native-<版本>-win-x64.zip`，ARM 处理器的电脑（如骁龙笔记本）选 `win-arm64`。不需要任何运行时，需要 Windows 10 1903 或更新版本。功能和设置说明见 [native/README.md](native/README.md)
- **WPF 版（1.x）**：`win-x64`、`win-arm64`，或已安装 .NET 8 桌面运行时的电脑用 `win-x64-framework-dependent`（体积更小）

两个版本共用设置和数据，可以来回切换，但不要同时运行。

系统要求：Windows 10 1809 或更高版本、Windows 11。想开机自动运行，右键胶囊勾选"开机自动启动"。

## 怎么用

- **展开**：把鼠标移到屏幕顶部正中的胶囊上（甩到屏幕最顶端也可以）。
- **收起**：鼠标离开就会收起。正在打字时不会因为鼠标移开而收起，按 `Esc` 或点击别处即可。
- **切换功能**：展开后点顶部的图标。下次展开时停在上次用的功能。
- **右键胶囊**：开关音量/亮度提示、开机自动启动、打开数据文件夹、开关剪贴板历史保存、退出。
- **置顶**：展开后点右上角的图钉，鼠标移开也保持展开，方便从别的窗口往中转站拖文件。再点一次或按 `Esc` 取消。
- **全屏时自动隐藏**：看视频、打游戏、放 PPT 时岛会自动让开。
- **音量 / 亮度提示**：调节系统音量或笔记本亮度时，岛会短暂显示一条进度。鼠标停在岛上滚动滚轮可以直接调音量。
- **待机收成细线**：没有音乐和通知时，岛缩成顶端的一条细线，不挡浏览器标签。鼠标碰到屏幕顶端正中就会展开。在"外观"里还可以让放音乐时也只显示细线（细线变成封面的颜色）。
- **放在左边或右边**：在"外观"里把位置改成左侧或右侧，岛贴在屏幕边的正中，鼠标碰到屏幕边就从侧面展开。只用于主显示器；如果主显示器左边或右边还接着另一块屏幕，鼠标会直接移过去，碰不到边，这时请用顶部。

## 功能

| 图标 | 功能 | 说明 |
|---|---|---|
| 🎵 | 音乐 | 读取系统媒体控制（SMTC），支持 Spotify、网易云音乐、QQ 音乐、媒体播放器、浏览器视频等。播放时胶囊显示封面、歌名和随封面变色的律动条；展开后可以上一首、播放/暂停、下一首，并显示进度和系统音量条。从音乐胶囊展开时会直接打开播放器。 |
| ✅ | 日常待办 | 回车添加，勾选完成后自动沉底，一键清除已完成。 |
| 📋 | 剪贴板历史 | 自动记录最近 50 条复制的文字，点一下重新复制。密码管理器标记为"不记录"的内容会被跳过。 |
| 📁 | 文件中转站 | 把文件拖到岛上暂存，之后从岛上拖到别处使用。双击打开，可以在资源管理器中定位。只记录路径，不复制文件。 |
| 🌐 | AI 翻译 | 边生成边显示。默认使用 Claude，也可以换成 OpenAI、DeepSeek、通义千问、Kimi、智谱、本地 Ollama，或者任何 Anthropic / OpenAI 格式的接口。中文翻成英文，其他语言翻成中文。可以一键粘贴剪贴板并翻译。 |
| 📊 | 系统监控 | CPU、内存占用和实时上传/下载网速。 |
| 🎨 | 外观 | 主题：黑夜、白天、跟随系统、按时间自动切换，或者自定义背景、文字和强调色。还可以设置待机样式、放音乐时是否收成细线，以及岛放在顶部、左侧还是右侧。 |

### 轻量

- 只在看得见的时候干活：律动条、播放进度、系统监控都只在对应界面显示时运行，收起后不占 CPU。
- 时钟每分钟只刷新一次。
- 剪贴板通过系统通知（`AddClipboardFormatListener`）获取变化，不轮询。
- 不点击岛就不会抢走焦点，也不会出现在任务栏和 Alt+Tab 里。

## AI 翻译的设置

第一次打开翻译标签时会进入设置页，之后点翻译面板上的齿轮图标可以随时修改。

1. **选服务**：Claude、OpenAI、DeepSeek、通义千问、Kimi、智谱、Ollama 本地，或者"自定义"。选好后会自动填上格式、请求地址和推荐模型。
2. **格式**：`Anthropic`（Messages API）或 `OpenAI 兼容`（Chat Completions）。用代理、中转或其他兼容服务时，选它支持的格式即可。
3. **地址**：留空就用默认地址。根地址、带 `/v1` 的地址或完整的接口地址都可以，下方会显示实际请求的地址。
4. **模型**、**Key**：模型名可以随便改。Key 会用 Windows DPAPI 加密后保存在本机，只有当前 Windows 用户能解密。本地服务（如 Ollama）不需要 Key。
5. 点 **测试** 会保存配置并翻译一句 Hello，确认能用。

每个服务的配置分开保存，来回切换不用重新填。没填 Key 时，官方 Claude 会读取环境变量 `ANTHROPIC_API_KEY`，官方 OpenAI 会读取 `OPENAI_API_KEY`。

默认使用 Claude（`claude-opus-5-5`），并把 effort 设为 low，让翻译更快、更省。预设里的模型名只是推荐值，如果服务商改了名字，直接在"模型"里改就行。

## 数据保存在哪

全部保存在 `%APPDATA%\Island\`，右键胶囊选择"打开数据文件夹"就能看到：

| 文件 | 内容 |
|---|---|
| `settings.json` | 上次的标签、主题与待机样式、各翻译服务的地址和模型、加密的 API Key、剪贴板保存开关 |
| `todos.json` | 待办 |
| `clipboard.json` | 剪贴板历史（可以在右键菜单里关闭保存，关闭时会删除这个文件） |
| `shelf.json` | 中转站里的文件路径 |
| `island.log` | 运行日志。遇到问题时可以附上这个文件 |

## 原生版

用 Rust 重写的更轻、更顺滑的版本：单个 exe 不到 1 MB，刚启动内存约 27 MB，动画全部交给系统合成器在独立线程上运行。包含 WPF 版的全部功能，另外还能显示其他软件的通知、提醒 AI 工具完成任务、停在屏幕两侧时收成竖胶囊。详见 [native/README.md](native/README.md) 和 [native/CHANGELOG.md](native/CHANGELOG.md)。

## 开发

需要 Windows 10 1809 及以上，以及 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。

```bash
dotnet run --project src/Island
```

```bash
dotnet test
```

也可以用 Visual Studio 2022 打开 `Island.sln`。

### 冒烟测试

`Island.exe --smoke-test <输出目录>` 会在真实窗口上走一遍所有状态和功能标签，检查状态切换和尺寸，并把每个界面截图保存成 PNG。结果写到 `report.txt`，全部通过时退出码为 0。设置环境变量 `ISLAND_DATA_DIR` 可以把数据目录指到别处，避免影响自己的数据。

### CI 与发布

每次推送，GitHub Actions 都会在 Windows 上依次编译、运行单元测试、发布单文件程序，并对发布出来的 exe 运行冒烟测试。截图作为 `smoke-test` 构件上传。

发布新版本：

1. 在 `CHANGELOG.md` 里写好新版本的说明（标题格式 `## [1.2.3]`）
2. 推送对应的标签

```bash
git tag v1.2.3
```

```bash
git push origin v1.2.3
```

CI 会用标签里的版本号构建，并自动创建 GitHub Release，附上 x64、arm64 和依赖运行时的三个压缩包，以及 SHA256 校验文件。

不想在本地打标签的话，也可以在 GitHub 的 Actions 页面选择 build 工作流，点 Run workflow，在 `main` 上运行并填入版本标签（如 `v1.2.3`）。CI 会在这个提交上创建标签和 Release。

## 目录结构

```
src/Island/
├── App.xaml(.cs)                 启动、单实例、全局样式
├── Core/                         状态与形状、主题计算、设置、JSON 存储
├── Animation/                    胶囊形状的物理弹簧动画、内容缓动
├── Interop/                      Win32：窗口样式、置顶、剪贴板监听、光标；Core Audio 音量接口
├── Media/                        SMTC 媒体会话、封面取色
├── Services/                     待办、剪贴板、中转站、翻译、系统监控、音量、亮度
└── Views/
    ├── IslandWindow.xaml(.cs)    胶囊窗口、状态机、悬停展开/收起、全屏隐藏
    ├── IslandWindow.Features.cs  功能标签、键盘输入、拖放、剪贴板监听
    ├── IslandWindow.Media.cs     音乐胶囊与播放器
    ├── IslandWindow.Theme.cs     主题切换
    ├── IslandWindow.Levels.cs    音量 / 亮度提示、滚轮调音量
    ├── ThemeManager.cs           主题颜色资源与过渡动画
    ├── IslandWindow.SmokeTest.cs 冒烟测试
    └── Panels/                   待办、剪贴板、中转站、翻译、监控、外观面板
tests/Island.Tests/               单元测试
```
